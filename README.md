# Wi-Fi Analyzer Tool

Це легкий десктопний інструмент на Python для моніторингу рівня сигналу Wi-Fi у реальному часі. Програма автоматично визначає вашу операційну систему, отримує дані про мережу та зберігає історію якості з'єднання у файл.

## 🚀 Основні можливості
- **Кросплатформеність:** Працює на Windows, macOS та Linux.
- **Моніторинг у реальному часі:** Візуальний індикатор рівня сигналу (шкала змінює колір залежно від якості з'єднання).
- **Логування:** Автоматичний запис даних про мережу у файл `wifi_history.txt` кожні 5 секунд.
- **Попередження:** Візуальне сповіщення, якщо сигнал стає занадто слабким.
- **Зручний інтерфейс:** Керування логами (відкриття папки та очищення історії) безпосередньо через інтерфейс програми.

## 🛠 Технології
- **Python 3.x**
- **Tkinter** (для графічного інтерфейсу)
- **Subprocess/Platform** (для взаємодії з системними командами Wi-Fi)

## 📋 Початок роботи

### Передумови

   ```

```bash

```

## ⚙️ Як це працює
- Програма використовує вбудовані системні утиліти (`netsh` для Windows, `airport` для macOS, `nmcli` для Linux) для отримання даних про Wi-Fi.
- Файл `wifi_history.txt` створюється автоматично в тій же директорії, де знаходиться скрипт.
- Індикатор сигналу автоматично змінює колір:
  - **Зелений:** > 75% (відмінно)
  - **Жовтий:** 40% - 75% (середньо)
  - **Червоний:** < 40% (низька якість)
